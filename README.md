# LRMLD — List Recursive Maximum-Likelihood Decoder

Реализация списочного RMLD-декодера для произвольных коротких линейных блочных кодов (ЛБК) на FPGA.

## О проекте

Рекурсивный декодер по максимуму правдоподобия (RMLD) — алгоритм декодирования, работающий по критерию максимума правдоподобия и использующий решётчатое представление кода. В отличие от алгоритма Витерби, RMLD обрабатывает секции решётки параллельно, что снижает вычислительную сложность и задержку.

В данной работе реализован **списочный** вариант RMLD: на выходе декодера формируется не одно кодовое слово, а список из `L` наиболее правдоподобных кодовых слов. Это даёт энергетический выигрыш и позволяет использовать декодер в составе каскадных кодовых конструкций.

## Ключевые особенности

- Декодирование произвольных коротких ЛБК (примеры в проекте — 16, 32, 64 бит).
- Метрика декодирования — корреляционная невязка (беззнаковая, с насыщением).
- Длина списка `L = 2..16`.
- Входные данные — мягкие решения в формате LLR.
- Тактовая частота — не менее 300 МГц (по результатам синтеза).
- Два режима работы:
  - `FSM = 0` — потоковая обработка (максимальная производительность).
  - `FSM = 1` — последовательно-параллельная обработка (экономия ресурсов).

## Архитектура

Декодер построен на двух базовых операциях:

- **MakeCBT** — прямое вычисление метрик для меток смежных классов на начальном уровне рекурсии (`MakeCBT-I`).
- **CombCBT** — объединение таблиц `CBT` нижних уровней; базовый элемент — блок сложения, сравнения и выбора списков.

Блоки сложения-и-выбора реализованы для фиксированных длин списков `L = 4, 8, 12, 16`, а также для произвольной длины меньше `L`.

Модули верхнего уровня генерируются автоматически скриптом `gen_top` (MATLAB) по заданному секционированию решётки, меткам `MakeCBT` и таблицам объединений `CombCBT`.
